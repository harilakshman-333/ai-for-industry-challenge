# Contributing to AI for Industry Challenge

Thank you for your interest in contributing to our AI for Industry Challenge project!

## Getting Started

1. **Fork the repository** and clone it locally
2. **Set up your development environment** following the [Setup Guide](docs/setup.md)
3. **Create a branch** for your feature or bugfix
4. **Make your changes** following our coding standards
5. **Test your changes** thoroughly
6. **Submit a pull request**

## Code Standards

### Python
- Follow PEP 8 style guide
- Use type hints where applicable
- Write docstrings for all functions and classes
- Maximum line length: 100 characters

### C++
- Follow ROS 2 C++ style guide
- Use meaningful variable names
- Comment complex logic

### ROS 2
- Follow ROS 2 package structure
- Use standard message types when possible
- Document all topics, services, and parameters

## Testing

- Write unit tests for new functionality
- Ensure all tests pass before submitting PR
- Include integration tests where appropriate

## Pull Request Process

1. Update documentation for any changed functionality
2. Add tests for new features
3. Ensure CI/CD pipeline passes
4. Request review from at least one team member
5. Address review comments promptly

## Code Review Guidelines

- Be respectful and constructive
- Focus on code quality and functionality
- Suggest improvements, don't just criticize
- Approve when satisfied with changes
