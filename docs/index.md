## 🎯 Project Goal

Develop a robust AI-powered robotic system capable of performing dexterous cable manipulation and connector insertion tasks in industrial settings.

## 🏆 Competition Information

- **Organizer:** Intrinsic (in partnership with Open Robotics)
- **Prize Pool:** $180,000
- **Registration Deadline:** April 17, 2026
- **Challenge Start:** February 11, 2026

## 🛠️ Technology Stack

- **Simulation:** Gazebo, NVIDIA Isaac Sim, MuJoCo
- **Framework:** ROS 2 (Humble)
- **Planning:** MoveIt2
- **ML/AI:** PyTorch, TensorFlow
- **Vision:** OpenCV, PCL (Point Cloud Library)
- **Development:** Intrinsic Flowstate (Phase 1+)
